    Este documento es obra de Claude, la IA de Anthropic. Es una reescritura, para C# 14 y la plataforma .NET 10, del curso “Aprendizaje de C# versión 3.0 con el framework .NET 3.5”, escrito por Serge Tahé en mayo de 2008. Conserva el plan, los ejemplos y el hilo conductor del curso, y actualiza el lenguaje, las bibliotecas y las herramientas:

    • el curso de 2008 usaba C# 3.0 y el framework .NET 3.5 en Windows con Visual C# 2008 Express. Desde entonces, C# ha tenido once versiones principales (de C# 4.0 en 2010 a C# 14 en 2025) y la plataforma .NET se ha reescrito por completo: ahora es de código abierto, multiplataforma (Windows, Linux, macOS) y se publica cada año. Este documento utiliza .NET 10 (noviembre de 2025, versión de soporte a largo plazo) y C# 14;
    • el capítulo sobre las interfaces gráficas de usuario con Windows Forms se ha eliminado: hoy en día, las aplicaciones de gestión se escriben con mayor frecuencia con interfaces web. El capítulo “Eventos de usuario”, que lo seguía, se ha reformulado como un capítulo sobre delegados, expresiones lambda y eventos, sin formularios;
    • Dos capítulos son nuevos: la programación asíncrona ([Task] tareas y [async] / [await], introducidos en 2012 con C# 5) y Entity Framework Core, la herramienta de mapeo objeto-relacional de .NET. El capítulo sobre las clases de .NET de uso frecuente ahora incluye LINQ (el curso de 2008 indicaba explícitamente que no lo trataba);
    • las herramientas han cambiado: el editor [VS Code] (o el IDE [Visual Studio 2026]) y el comando [dotnet] sustituyen a Visual C# 2008 Express; el framework de pruebas [MSTest] sustituye a [NUnit 2]; la inyección de dependencias que proporciona [Microsoft.Extensions.DependencyInjection] sustituye a [Spring.NET]; el SGBD [MySQL] (proporcionado por [Laragon]) y el conector [MySqlConnector] sustituyen a SQL Server 2005 Express; la clase [HttpClient] sustituye a [WebClient] y [WebRequest], que han quedado obsoletas; los servicios web REST / JSON escritos con ASP.NET Core sustituyen a los servicios web SOAP y [ASMX];
    • todo lo que ha quedado obsoleto se ha eliminado o se ha señalado como tal, y cada capítulo presenta las últimas novedades del lenguaje y de la plataforma en el momento de la redacción.

    Este documento no es un curso exhaustivo. Al igual que la edición de 2008, está dirigido a lectores que ya tienen experiencia en programación y desean aprender los fundamentos de C#. Se basa en ejemplos: más de doscientos programas (cerca de trescientos archivos C#), la mayoría breves, con comentarios línea por línea.

    1.1. C# y .NET de 2002 a 2026

    C# apareció en febrero de 2002, junto con la plataforma .NET 1.0 de Microsoft, a la que está ligado. La plataforma .NET es un entorno de ejecución similar a la máquina virtual de Java: los compiladores de los lenguajes .NET (C#, F#, VB.NET) generan un código intermedio (IL, “Intermediate Language”) que la máquina virtual de .NET (el CLR, “Common Language Runtime”) compila sobre la marcha en código máquina. Todas las clases de la plataforma están disponibles para todos los lenguajes .NET.

    En 2008, el curso indicaba que .NET solo se ejecutaba en Windows y que el proyecto Mono permitía utilizarlo, de manera limitada, en Unix y Linux. La situación ha cambiado considerablemente:

    • 2016: .NET Core 1.0. Microsoft lanza una nueva implementación de .NET, de código abierto (licencia MIT, código disponible en GitHub) y multiplataforma: Windows, Linux y macOS. El antiguo framework “.NET” (.NET Framework 4.x) sigue recibiendo soporte para las aplicaciones Windows heredadas, pero ya no evoluciona;
    • 2020: .NET 5. .NET Core pasa a llamarse simplemente “.NET”: una única plataforma para todos los usos (consola, web, escritorio, móvil, nube);
    • Desde 2020: cada año, en noviembre, se publica una nueva versión de .NET. Las versiones pares (.NET 6, 8, 10) tienen soporte extendido (LTS, tres años); las versiones impares (.NET 7, 9) tienen soporte estándar (STS: dieciocho meses, ampliado a dos años a partir de .NET 9). Cada versión de .NET incorpora una nueva versión de C#;
    • Noviembre de 2025: .NET 10 (LTS) y C# 14, que son los que se utilizan en este documento. .NET 10 tiene soporte hasta noviembre de 2028.

    El curso de 2008 señalaba también que en 2002 C# era en gran medida una copia de Java y que resultaba fácil pasar de uno a otro, pero que desde entonces los dos lenguajes habían desarrollado características propias. La distancia se ha ampliado: a lo largo de sus diversas versiones, C# ha incorporado conceptos de los lenguajes funcionales (expresiones lambda, LINQ, coincidencia de patrones, records, tipos inmutables), la programación asíncrona ([async] / [await], que JavaScript, Python y Rust han adoptado después) y un sistema de tipos que detecta las referencias nulas en tiempo de compilación.

    1.2. Contenido del documento

    Este documento incluye los siguientes capítulos:

    • Capítulo 7: Delegados, expresiones lambda y eventos;
    • Capítulo 8: Hilos de ejecución y sincronización;
    • Capítulo 9: Programación asíncrona;
    • Capítulo 10: Acceso a bases de datos con ADO.NET;
    • Capítulo 11: Entity Framework Core;
    • Capítulo 12: Programación web (TCP/IP, clientes y servidores TCP, HTTP con [HttpClient]);
    • Capítulo 13: Servicios web con ASP.NET Core;
    • Capítulo 14: Para profundizar;
    • Apéndices: Instalación de Laragon y MySQL.

    1.3. El hilo conductor: el cálculo del impuesto

    Como en 2008, el mismo problema se retoma a lo largo de todo el documento: calcular el impuesto sobre la renta de un contribuyente que solo debe declarar su salario. La escala impositiva utilizada es la del curso original (ingresos de 2003): ya no está vigente, pero basta para nuestro propósito, que es escribir la misma aplicación de varias maneras distintas.     Los programas pequeños son aplicaciones de un solo archivo: un único archivo llamado [.cs], que se ejecuta con el comando [dotnet run file.cs] (Capítulo 2). Los programas de varios archivos son proyectos ([.csproj]) agrupados en una solución ([.slnx]) por capítulo.

    Todos los programas de este documento se compilaron sin errores ni advertencias con el SDK de .NET 10 y luego se ejecutaron. Los resultados reproducidos en el documento son los de esas ejecuciones. Los resultados del Capítulo 3 se obtuvieron con la configuración regional francesa (fr-FR), como en una estación de trabajo Windows en francés: los números reales se muestran con coma decimal y las fechas están en francés. Los capítulos posteriores se ejecutaron con la configuración regional del inglés de Estados Unidos (en-US): punto decimal, coma como separador de millares, fechas en formato mes/día/año. Dos notas:

    • los mensajes de error de la plataforma .NET (mensajes de las excepciones) están en inglés: .NET no ofrece traducciones al francés de estos mensajes;
    • los ejemplos se ejecutaron en Linux. En su mayor parte, esto no supone ninguna diferencia: .NET es multiplataforma. Las pocas diferencias (rutas de archivo con / en lugar de \, finales de línea) se señalan donde aparecen.

    Los resultados de los programas con múltiples hilos, asíncronos o de red, así como los tiempos de ejecución medidos, pueden variar de una ejecución a otra: los comentarios se centran en lo que es reproducible.

    • las sucesivas ediciones de “C# in a Nutshell” de Joseph Albahari (O’Reilly), que siguen siendo una excelente referencia.
